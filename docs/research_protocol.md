# Initial Research Protocol

## Question
Do quarter-to-quarter changes in earnings-call language
improve predictions of 20-session sector-relative returns
beyond price-based features?

## Initial universe
Software companies with available historical transcripts.

## Initial development sample
Two consecutive Microsoft earnings-call transcripts.

## Transcript features
- Guidance changes.
- Demand changes.
- Margin discussion changes.
- Uncertainty changes.
- Differences between prepared remarks and Q&A.

## Timing requirement
Historical model inputs must have been available before
the simulated investment decision.

## Evaluation
Compare a price-based baseline with the same model
plus transcript features using chronological splits.

## Decisions still to finalize
- Sector benchmark.
- Historical company coverage.
- Exact executable entry and exit rules.
- Historical publication-time availability.
