# EarningsScope

## Purpose
Help portfolio managers identify important changes across
earnings calls and investigate their implications for holdings.

## Core workflow
1. Upload current and previous quarterly transcripts.
2. Separate prepared remarks from analyst Q&A.
3. Identify changes in guidance, demand, margins, and uncertainty.
4. Display findings alongside their supporting passages.
5. Connect findings to a watchlist and uploaded holdings.
6. Evaluate whether transcript changes predict subsequent
   sector-relative returns.

## Month-one scope
- English TXT and text-based PDF uploads.
- One sector.
- Quarter-to-quarter comparisons.
- Evidence-linked findings.
- One simple prediction model.
- A 20-trading-session prediction horizon.
- Holdings CSV upload.
- A deployed web application.

## Deferred features
- Live audio and transcription.
- Automated trade execution.
- Advanced portfolio optimization.
- Broad automated website scraping.

## Success criteria
A user can upload two calls, inspect supported changes,
and identify relevant holdings through the deployed app.
Research results are reported honestly, including when
transcript features do not improve predictions.
